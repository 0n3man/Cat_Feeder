The files in this directory can be copied to /var/www/html or whatever directory the raspberry pi camera interface sits in.  In reality webcam.php is really just the default index.php file that comes with RPi Cam Control. As such if you have an updated version of RPi Cam Control you may want to use it's version of index.php, renamed to wepcam.php.  The index.php file simply creates the two frames, one for the cam control and one for the gimbal controls.  The version I used when I built this was v6.4.34
